# Melio fictional fixture

A self-contained fictional fixture for offline agent and policy demonstrations. It makes no HTTP calls and reads no secrets.

- `submilli.toml` declares `@pirlo-labs/melio-demo`.
- [The package](packages/melio-demo/README.md) contains the fixture implementation, capabilities, documentation, and tests.
- [The operation reference](packages/melio-demo/docs/readme.md) describes the `melio.com/...` capabilities and fictional data.
