# Demo data: @pirlo-labs/melio-demo

A self-contained fictional Melio fixture package for agent and policy demonstrations. It makes no HTTP calls and reads no secrets.

Install it in a blueprint as `@pirlo-labs/melio-demo`. The package has no infrastructure grants. Grant the required `melio.com/...` capabilities to `main` to control access to fixture operations.

See [the package documentation](docs/readme.md) for the operations, fictional coverage, and capability fields.
